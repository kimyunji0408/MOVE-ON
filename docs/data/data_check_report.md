## 서울교통공사 교통약자 시설정보 API 데이터

확인일: 2026-08-14

### 확보 목표
MOVE:ON의 경로 이용가능성 판단에 사용할 지하철역별 교통약자 시설 정보를 확보한다. 이번 단계의 대상 시설은 엘리베이터와 휠체어리프트다.

### 현재 확보 상태
- 원본 저장 예정 위치: `data/raw/accessibility/`
- 전처리 저장 예정 위치: `data/processed/accessibility/`
- 검증/전처리 스크립트: `scripts/check_accessibility_api.py`
- 실제 원본 응답 파일: 아직 없음
- 실제 processed 파일: 아직 없음

### 후보역 데이터 존재 여부
외부 API 호출이 완료되지 않아 후보역별 실제 데이터 존재 여부는 아직 미확인이다.

- 불광: 미확인
- 독바위: 미확인
- 연신내: 미확인
- 녹번: 미확인
- 응암: 미확인

### 전처리 예정 필드
- 역사명
- 역사코드
- 호선
- 시설 구분: 엘리베이터 또는 휠체어리프트
- 출입구 또는 인접 출입구 정보
- 상세 위치
- 운영상태

운영상태 필드가 원본 API에 없거나 값이 비어 있으면 `운영상태 미확인`으로 기록한다. 시설 존재 여부만으로 항상 이용 가능하다고 판단하지 않는다.

### 미확인 사유
현재 작업 환경에서 Python 런타임이 실행되지 않았고, PowerShell 기반 API 호출은 샌드박스 네트워크 제한으로 실패했다. 외부 API 호출 승인 요청이 거절되어 실제 응답을 저장하지 못했다.
